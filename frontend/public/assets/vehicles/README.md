# Asset veicoli

Inserire qui gli asset reali, senza modificare gli originali, organizzati per categoria:

`city-car/`, `station-wagon/`, `minibus/`, `suv/`, `van/`

Per ogni modello il catalogo in `src/components/configurator/data/vehicles.js` dovrà
referenziare miniatura, vista `front`, vista `rear` e le maschere per zona. I nomi dei
file non sono predefiniti: verranno aggiunti quando sarà disponibile la libreria reale.
